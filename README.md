# Paul Excavation

Site web statique pour l'entreprise Paul Excavation.

## Pages disponibles

- `index.html` : page d'accueil
- `a-propos.html` : page À propos
- `projets.html` : page Projets
- `gallery.html` : page Galerie
- `contact.html` : page Contact
- `admin.html` : page pour modifier les photos de la galerie

## Utilisation

Ouvrez `index.html` dans votre navigateur web.

Pour modifier les photos de la galerie, allez sur `admin.html` et collez les URLs d'images dans les champs puis cliquez sur « Enregistrer les photos ». Les images sont stockées localement dans le navigateur via `localStorage`.
